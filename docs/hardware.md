# 硬件：选型、引脚、接线、电源

> 这一页的目标是：你照着表格接完线就能跑，不需要回去翻原理图。

---

## 1. 为什么是这几个件

### 主控：ESP32-S3

真正的原因只有一条：**它有两个独立的 I2S 控制器**（I2S0 和 I2S1）。

麦克风和功放都想当 I2S 主机、都想要自己的时钟；如果只有一个 I2S，你就得让它们共用 BCLK/WS，
而 INMP441 和 MAX98357 对时钟相位的要求并不完全一样，共用会引入很难查的噪声。
两个控制器各管一路，代码是直的，硬件也不用配时钟树。

顺带的好处：240 MHz 双核、片上 Wi-Fi、8 MB PSRAM 可选（本项目不用 PSRAM，但留给以后做本地唤醒词）。

**不要用 ESP32（老款）**：它只有两个 I2S，但 GPIO 矩阵和 DMA 的行为差异会让这套代码要改不少地方。
**ESP32-C3 只有一个 I2S**，直接排除。

### 麦克风：INMP441

- **数字输出**：I2S 直出 24 bit，不用 ADC、不用运放、不用考虑模拟走线和电源噪声。
- 便宜、模块化、3.3 V 单电源。
- 信噪比够用（61 dB），对「听人说话」这个场景绰绰有余。

替代品：ICS-43434（更好但贵、难买）、MSM261S4030H0（便宜但一致性差）。
如果只要「能听见」，INMP441 是性价比拐点。

### 功放：MAX98357A

- **I2S 输入 + 内置 DAC + D 类功放**，一颗芯片从数字信号直接推到喇叭。
- 5 V 供电、4Ω 负载下 3.2 W，音量对一个小房间足够。
- 模块自带关断（SD）和增益（GAIN）脚——虽然本项目为了简单让它们悬空（见 §5）。

替代品：PCM5102 + PAM8403（要两级、要模拟走线，不推荐）；
MAX98357 的兄弟 MAX98358 是差分输入，除非你已经有差分源否则没必要。

### 采样率：16 kHz / 16 bit / 立体声

- **16 kHz**：人声有效带宽 8 kHz，电话标准；再高只是浪费带宽，语音识别也吃不到好处。
- **16 bit**：12 bit 就够听，但 16 bit 是 WAV / PCM 的通用宽度，省掉所有转换。
- **立体声（哪怕麦克风是单声道）**：让每个包正好是 4 字节一帧，两端都不用处理奇数字节，
  而且以后想加第二个麦克风做双麦降噪时协议不用改。代价是带宽翻倍——16 kHz × 4 B = **512 kbit/s**，局域网里不算什么。

## 2. 参考板：WangXun V1.0 语音板

本项目是在一块现成的 ESP32-S3 语音板上验证的（61 × 46 mm，2 层板，嘉立创 EDA 设计，
作者署名 WangXun，标题「基于 esp32-s3-wroom 实现的智能语音聊天机器人」）。
它本来是给小智（xiaozhi）那类语音助手用的，元件都已经焊好，拿来当音频前端正合适。

板上有什么：

| 部件 | 型号 | 备注 |
|---|---|---|
| 主控 | ESP32-S3-WROOM-1 | 实物是 **N16R8**（16 MB Flash + 8 MB 八线 PSRAM）；BOM 标的是 N8R2，以实物为准 |
| 麦克风 | INMP441 模块 | 直接放在板上，圆形开孔对准进音孔 |
| 功放 | MAX98357A 模块 | 插在排母上 |
| 喇叭座 | 1.25 mm + 2.0 mm 两个 | **并联**的，接 `S+/S-`，任选一个 |
| 指示灯 | WS2812E | 接 GPIO45（strapping 脚，上电瞬间会闪一下，正常） |
| 电源 | USB-C → 保险丝 F1 → SMAJ5.0CA TVS → 5 V → AMS1117-3.3 | 板上**没有**外部电源接口 |
| 按键 | 2 个 | 「重启」(EN) 和「录音测试」(IO1→GND)，**没有 BOOT 键** |
| 烧录 | 6 针 2.54 排针 | GND / 3.3V / RXD0 / TXD0 / RTS / DTR，也有自动下载电路（SS8050 ×2） |
| 扩展 | GH1.25 9P 座（U4） | 3.3V、IO8~IO14、GND，每针约 1 A，**只能走信号** |

### 实测引脚（就是 `config.h` 里的默认值）

| 功能 | 信号 | GPIO |
|---|---|---|
| 麦克风 | BCLK (SCK) | **4** |
| 麦克风 | WS (LRCLK) | **5** |
| 麦克风 | DIN (SD) | **6** |
| 功放 | BCLK | **16** |
| 功放 | LRC | **17** |
| 功放 | DIN | **15** |

串口走的是 **S3 原生 USB**（VID `303A` / PID `1001`），插上就是一个 COM 口，
**不需要 CH343 / CP210x 驱动**。没有 BOOT 键时，短接模块的 IO0 到 GND 再点复位即可进下载模式。

## 3. 面包板接线（自己搭的话）

只接六根信号线 + 电源地。**不需要 MCLK**。

### INMP441 模块（6 脚）

| 模块脚 | 接到 | 说明 |
|---|---|---|
| VDD | 3.3 V | **不要接 5 V** |
| GND | GND | |
| L/R | **GND** | 接 GND = 数据在左声道；接 VDD = 右声道。**悬空会读到全 0** |
| WS | GPIO5 | |
| SCK | GPIO4 | |
| SD | GPIO6 | |

### MAX98357A 模块（7 脚 + 喇叭）

| 模块脚 | 接到 | 说明 |
|---|---|---|
| VIN | 5 V | 3.3 V 也能响，但音量小很多 |
| GND | GND | |
| SD | 悬空（或接 3.3 V） | 低电平 = 关断。悬空时模块内部上拉 = 常开 |
| GAIN | 悬空 | 悬空 = 9 dB。接 GND = 15 dB，接 VDD = 3 dB，经 100 kΩ 分压还能更细 |
| DIN | GPIO15 | |
| BCLK | GPIO16 | |
| LRC | GPIO17 | |
| + / − | 喇叭 | 接反只会相位相反，**单只喇叭听起来一样，也不会坏** |

### 电源

- 3.3 V 给 ESP32 和 INMP441，5 V 只给 MAX98357。
- **共地**：麦克风、功放、主控必须同一个 GND，否则会有嗡嗡声。
- 麦克风的 SCK/WS 和功放的 BCLK/LRC 是两套**独立时钟**，不要为了「省两根线」把它们接在一起。

### 另一种接法：GOOUUU 果云版 42 脚开发板（`BOARD_BREADBOARD`）

上面 §3 的三张表用的是**参考板**的引脚。如果你手上是那种 42 脚的
ESP32-S3-DevKitC-1（GOOUUU 果云版，比乐鑫标准版少几个引脚、左侧多了 GPIO19/20），
按小智 AI 那套面包板教程的「果云版」接线，引脚是另一套 ——
**改 `config.h` 顶部的 `BOARD_PROFILE` 为 `BOARD_BREADBOARD`，再重烧**，线不用动。

| 功能 | 参考板（`BOARD_INTEGRATED`） | 面包板（`BOARD_BREADBOARD`） |
|---|---|---|
| INMP441 SCK (BCLK) | GPIO **4** | GPIO **5** |
| INMP441 WS | GPIO **5** | GPIO **4** |
| INMP441 SD (DIN) | GPIO 6 | GPIO 6 |
| MAX98357 BCLK | GPIO 16 | GPIO **15** |
| MAX98357 LRC (WS) | GPIO 17 | GPIO **16** |
| MAX98357 DIN | GPIO 15 | GPIO **7** |
| 送话按键 | IO1（板上自带） | GPIO **0**（板上 BOOT 键） |

```
INMP441    SCK→GPIO5   WS→GPIO4   SD→GPIO6   VDD→3V3   GND→GND   L/R→GND
MAX98357   BCLK→GPIO15 LRC→GPIO16 DIN→GPIO7  VIN→5V    GND→GND   GAIN→GND
```

四个会让人白折腾半天的点：

1. **BCLK 和 WS 是交叉的**（4/5 ↔ 5/4）。接反不会声音小，是彻底没声，
   而串口日志一切正常 —— 极易误判成"固件坏了"。
2. **L/R 必须接 GND**（悬空会读到全 0，推上去是一整片静音）。
3. **3V3 / GND 排针不够分**：麦克风、功放、按键都要电和地。
   买几条 1 分 2 的分叉杜邦线，或者把面包板的电源轨拉出来用。
4. 按键用 BOOT（GPIO0）的副作用：**开机时按住会进下载模式**。正常使用没影响；
   嫌碍事就换到任意空闲 GPIO 并改 `PIN_BTN`。

## 4. 电流与供电

功放是这套东西里唯一吃电流的部件。

| 状态 | 5 V 侧电流 | 说明 |
|---|---|---|
| 待机（ESP32 连 Wi-Fi） | 约 100 ~ 150 mA | Wi-Fi 发射瞬间有尖峰 |
| 说话（中等音量） | 约 300 ~ 500 mA | 估算值，随音量变化很大 |
| 大声 + 低音 | 可能超过 1 A | 4Ω 3W 满载，**待实测** |

结论：

- **电脑 USB 口直接供**：一般能跑，但大声时会掉压重启。USB 2.0 口只保证 500 mA。
- **推荐**：5 V / 2 A 的独立电源，或者带外部供电的 USB Hub。
- 板子上的 AMS1117 是 SOT-223 线性稳压，5 V→3.3 V 压差 1.7 V，Wi-Fi 尖峰时它会发热。
  这属于「能用但不优雅」，不追求体积的话，用 MP1584 之类的开关降压更稳。

## 5. 硬件上的坑

1. **INMP441 的 L/R 悬空** → 读出来恒为 0，而且不报错。第一次调试先确认这一脚接地。
2. **麦克风只有左声道有数据**（L/R 接地时右声道是静音）。量电平要取左声道，
   不然会得到「音量总是很小」的错觉。
3. **喇叭接反不坏**，只是相位 180°；两只喇叭做立体声时才需要一致。
4. **功放的 SD / GAIN 悬空** = 常开 + 9 dB，**没有硬件音量**。音量只能靠软件幅度
   （客户端里 `gain` 参数），或者给 GAIN 脚接电阻。
5. **天线**：模块天线区下方和前方不要铺铜、不要放金属、离喇叭磁体远一点，
   否则 Wi-Fi 距离会莫名其妙变短。
6. **USB-C 只供电不通信**，但板子同时会把原生 USB 枚举成一个 COM 口——插上就能烧录。
7. **没有防反接**：TVS 是双向钳位，不是肖特基。外部电源正负接反会直接烧，接之前量一下。
